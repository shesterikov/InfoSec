# Лекция 1. Введение в информационную безопасность

## Основные вопросы
- Основные понятия информационной безопасности
- Объекты защиты информации
- Модель CIA: конфиденциальность, целостность, доступность
- Дополнительные свойства безопасности: аутентичность, подотчётность, неотказуемость, приватность
- Угроза, уязвимость, риск
- Поверхность атаки
- Модель нарушителя: мотивация, ресурсы, возможности и цели
- История компьютерной безопасности
- Современный ландшафт киберугроз
- Экономика киберпреступности и Ransomware-as-a-Service
- Классификация компьютерных атак
- Анализ реальных инцидентов информационной безопасности
