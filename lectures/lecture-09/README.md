# Лекция 9. Уязвимости обработки входных данных и управления памятью

[← Программа курса](../../README.md#программа-курса)

## Основные вопросы
- Валидация входных данных.
- SQL Injection.
- Command Injection.
- Path Traversal.
- SSRF.
- Небезопасная десериализация.

## Ошибки управления памятью
- Стек и куча;
- Переполнение стека (Stack Buffer Overflow);
- Переполнение кучи (Heap Overflow);
- Integer Overflow;
- Out-of-Bounds Read/Write.
- Современные механизмы защиты (ASLR, DEP/NX, Stack Canary).
- О memory-safe языках.
