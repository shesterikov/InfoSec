# Лекция 3. Анализ сетевого взаимодействия и сетевые атаки

[← Программа курса](../../README.md#программа-курса)

## Основные вопросы
- Локальные и глобальные компьютерные сети (LAN и WAN)
- IP-адресация, частные и публичные адреса
- Маршрутизация, шлюз по умолчанию и NAT
- Протокол ARP и атаки ARP Spoofing, ARP Table Overflow
- Протокол DHCP и атаки DHCP Starvation, Rogue DHCP Server
- Протокол DNS и основные типы DNS-записей
- DNS Spoofing
- Атаки Man-in-the-Middle (MITM)
- Proxy и Reverse Proxy
- Атаки на доступность: DoS и DDoS
- Основы балансировки нагрузки и её роль в обеспечении доступности
- Межсетевые экраны (Firewall)
- Демилитаризованная зона (DMZ) и сегментация сети
- Web Application Firewall (WAF) и его отличия от Firewall
- Многоуровневая защита сетевых приложений
