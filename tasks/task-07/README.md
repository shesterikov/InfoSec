# Практическая работа 7

## SQL-инъекции: обнаружение, эксплуатация и защита

### Цель работы

Познакомиться с SQL-инъекциями, получить практические навыки их обнаружения с использованием Metasploit Framework, самостоятельного поиска и применения специализированных инструментов Kali Linux, а также освоить методы защиты от SQLi, включая параметризованные запросы и валидацию ввода.

### Технические требования:

- Наличие интернет-соединения
- Наличие [Docker](https://docs.docker.com/desktop/) и [Docker Compose](https://docs.docker.com/compose/install/)
- Наличие [cURL](https://curl.se/download.html/) и [Postman](https://www.postman.com/downloads/)
- Базовые знания SQL (SELECT, WHERE, операторы сравнения, комментарии -- и #)

### Ход работы:

1. Запустите приложение при помощи команды
   `docker compose up -d --build`

2. Убедитесь, что приложение запущено корректно.
3. Выполните вход, используя следующие данные

```
username: user1
password: 22221
```

Убедитесь, что вход не выполнен.

4. Выполните вход, используя корректные данные

```
username: user1
password: password1
```

Убедитесь, что входе выполнен.

5. Выполните вход, используя в качестве `username` следующее значение

```
' OR '1'='1' --
```

Поле `password` при этом оставьте пустым
В случае успеха произойдет обход аутентификации (bypass authentication).

6. Выполните проверку серверных логов при помощи команды `docker logs app`
   Ознакомьтесь с тем, в каком виде при запросах к серверу были представлены изначальные и модифицированный запросы:
   - Исходный SQL-запрос (при корректном входе)
   - Модифицированный запрос (при SQLi-атаке)
   - Объясните, почему атака сработала

7. Подключитесь к контейнеру Kali Linux
`docker exec -it kali -sh`

8. Убедитесь, что из контейнера Kali Linux (или хоста) доступен сервис приложения

9. Запустите Metasploit Framework

10. Используйте вспомогательные модули Metasploit для сканирования веб-уязвимостей, связанных с SQL

11. Зафиксируйте результаты сканирования:
    - Какие параметры оказались уязвимы?
    - Какие payload были использованы модулем?
    - Какой тип инъекции обнаружен (error-based, blind, union-based)?

12. Найдите в Kali Linux специализированный инструмент для автоматического обнаружения и эксплуатации SQL-инъекций:
    - Изучите его базовое использование (--help)
    - Просканируйте уязвимый эндпоинт (форму логина)
    - Извлеките информацию о базе данных (имя БД, таблицы, пользователи)

13. Зафиксируйте результаты работы специализированного инструмента:
    - Какие типы инъекций были обнаружены?
    - Какую информацию удалось извлечь?
    - Какие дополнительные возможности предоставляет инструмент по сравнению с Metasploit?       

14. Выполните SQLi для модификации пароля пользователя admin.
    Проверьте, удалось ли изменить пароль.

15. Модифицируйте исходный код main.go для защиты от SQLi. С этой целью воспользуйтесь параметризированными запросами и примерами, представленными в документации.

16. Проверьте корректность настройки защиты:
    - Повторите шаги 3–5 и убедитесь, что SQL-инъекция больше не срабатывает
    - Убедитесь, что легитимный вход с корректными данными работает

17. Повторите автоматизированное сканирование (шаги 10–14) и зафиксируйте, что уязвимость более не обнаруживается.
