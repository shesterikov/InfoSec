# Практическая работа 5

## XSS уязвимости и способы защиты от них

### Цель работы

Получить практические навыки выявления XSS-уязвимостей с использованием автоматизированных инструментов Kali Linux и применения методов защиты от них, включая настройку CSP и санитизацию контента

### Технические требования:

- Наличие [Docker](https://docs.docker.com/desktop/) и [Docker Compose](https://docs.docker.com/compose/install/)
- Наличие [cURL](https://curl.se/download.html) / [Postman](https://www.postman.com/downloads/) / [Insomnia](https://insomnia.rest/download)
- Современный браузер с поддержкой Web Crypto API
- Наличие [KaliLinux] (https://hub.docker.com/r/kalilinux/kali-rolling)

### Ход работы:

Данная практическая работа является прямым продолжением практической работы №4, поэтому наличие кода, связанного с e2e шифрованием будет приветствоваться.

1. Запустите приложение и Kali при помощи команды
   `docker compose up -d --build`
2. Убедитесь, что приложение запущено корректно при помощи следующего cURL запроса

```cURL
curl --location 'http://localhost:3000/health'
```

В случае успешного запуска при выполнении cURL запроса отображается следующий текст
![Рисунок 6.1 - Главный экран Postman с успешным ответом от API](/assets/task-05/1.png)

3. Откройте две вкладки в браузере со [следующим](http://localhost:3000) URL адресом
4. Введите произвольный текст сообщения в первой вкладке и отправьте его
5. Удостоверьтесь, что аналогичный текст представлен во второй вкладке
   ![Рисунок 6.2 - Основной экран чата с полученным сообщением](/assets/task-05/2.png)

6. Введите следующий код в поле ввода

```
<img src='x' width="0" height="0" onerror='alert("XSS")'>
```

7. Убедитесь, что другой вкладке отобразилось сообщение с надписью XSS
   ![Рисунок 6.3 - Пример использования XSS уязвимости](/assets/task-05/3.png)

8. Подключитесь к контейнеру Kali Linux.

9. Убедитесь, что из контейнера Kali Linux доступен сервис приложения.

10. Запустите Metasploit Framework внутри контейнера Kali Linux.

11. Используйте вспомогательный модуль для сканирования на XSS.
Самостоятельно найдите информацию о вспомогательных модулях Metasploit для сканирования веб-уязвимостей.
`Обратите внимание: в качестве цели укажите сетевой алиас target, а не localhost или 127.0.0.1`

12. Зафиксируйте результаты сканирования: какие параметры оказались уязвимы, какие payload были использованы.

13. Рассмотрите иные методы автоматизированного поиска уязвимостей Kali Linux.
Проведите сравнительный анализ методов: 
- Какие альтернативы Metasploit вы нашли?
- Чем они отличаются по функционалу, скорости, точности, для каких целей используются?
- Какие результаты дало сканирование каждым из инструментов?

14. Модифицируйте исходный код `public/index.html` для устранения XSS уязвимости. Добавьте CSP политики, санитизацию вводы, экранирование вывода.

15. После внесения изменений пересоберите и перезапустите приложение.

16. Проверьте корректность настройки защиты.
Откройте в браузере адрес приложения.
Повторите шаг 4 и убедитесь, что XSS-атака больше не срабатывает.

17. Повторите автоматизированное сканирование (шаги 7–10) и зафиксируйте, что уязвимость более не обнаруживается.
