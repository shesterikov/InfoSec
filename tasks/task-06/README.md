# Практическая работа 6

## Атаки на пароли

### Цель работы

Получить практические навыки анализа устойчивости паролей к атакам методом полного перебора и словарной атаки на примере защищённых ZIP-архивов.

### Технические требования:

- Наличие [Docker](https://docs.docker.com/desktop/) и [Docker Compose](https://docs.docker.com/compose/install/)
- Наличие терминала с возможностью выполнения команд Docker

### Постановка задачи:

В ходе работы необходимо исследовать два защищённых паролем ZIP-архива и сравнить эффективность различных методов подбора пароля.

Для первого архива пароль присутствует в словаре `rockyou.txt`. Необходимо выполнить словарную атаку и определить пароль.

Для второго архива пароль отсутствует в словаре. Необходимо выполнить подбор методом полного перебора.

В результате работы необходимо:

- получить данные, необходимые для подбора паролей;
- выполнить словарную атаку;
- выполнить атаку методом полного перебора;
- сравнить время и особенности работы двух методов;
- оценить влияние длины и используемого алфавита на количество возможных паролей;
- сделать вывод о требованиях к устойчивому паролю.

### Теоретические сведения

Пароль защищённого архива невозможно проверить простым сравнением с заранее известным значением. При отсутствии пароля злоумышленник может последовательно проверять различные варианты до тех пор, пока один из них не позволит открыть архив.

Такой подход называется атакой методом полного перебора (brute force).

Количество возможных вариантов зависит от длины пароля и количества допустимых символов.

Таким образом, увеличение длины пароля приводит к существенному увеличению пространства поиска.

Другой распространённый подход — словарная атака. Вместо перебора всех возможных комбинаций используются заранее подготовленные списки часто используемых паролей, слов и их вариантов.

Словарная атака значительно сокращает количество проверяемых вариантов, если пароль пользователя является распространённым или присутствует в используемом словаре.

В работе используется словарь `rockyou.txt`, содержащий большой набор распространённых паролей.

Для выполнения атак используется John the Ripper.

Для работы с ZIP-архивами используется утилита `zip2john`. Она не выполняет подбор пароля самостоятельно, а извлекает из ZIP-архива данные, которые позволяют John the Ripper проверять различные варианты пароля.

В первой части работы словарная атака должна найти пароль `dictionary.zip`.
Во второй части работы словарная атака не должна найти пароль `bruteforce.zip`, после чего выполняется полный перебор.

### Ход работы:

1. Запустите приложение при помощи команды:

```text
docker compose up -d --build
```

Подключитесь к запущенному контейнеру:

```text
docker exec -it kali bash
```

1. Подготовьте словарь паролей

Перейдите в каталог со словарями:

```text
cd /usr/share/wordlists/
```

Если файл словаря находится в сжатом виде, распакуйте его:

```text
gunzip rockyou.txt.gz
```

Убедитесь, что словарь доступен:

```text
ls -lh rockyou.txt
```

Количество записей в словаре можно определить при помощи команды:

```text
wc -l rockyou.txt
```

3. Перейдите в каталог с учебными архивами:

```text
cd /app/data
```

Убедитесь, что в каталоге находятся два архива:

```text
dictionary.zip
bruteforce.zip
```

Первый архив предназначен для демонстрации словарной атаки.
Второй архив предназначен для демонстрации полного перебора.

4. Получите данные для подбора пароля первого архива

Для архива `dictionary.zip` выполните:

```text
zip2john dictionary.zip > dictionary.txt
```

Полученный файл `dictionary.txt` содержит данные, необходимые John the Ripper для проверки вариантов пароля.

5. Выполните словарную атаку

Запустите подбор пароля при помощи словаря:

```text
time john --wordlist=/usr/share/wordlists/rockyou.txt dictionary.txt
```

После завершения работы John the Ripper отобразит найденный пароль.

Получить найденные пароли также можно при помощи команды:

```text
john --show dictionary.txt
```

Зафиксируйте время выполнения атаки.

6. Проверьте полученный пароль

Разархивируйте данные:

```text
unzip dictionary.zip
```

Введите найденный пароль.

Убедитесь, что содержимое архива успешно извлечено.

7. Подготовьте второй архив

Для второго эксперимента используется архив:

```text
bruteforce.zip
```

Получите данные для John the Ripper:

```text
zip2john bruteforce.zip > bruteforce.txt
```

8. Проверьте возможность словарной атаки

Попробуйте подобрать пароль второго архива с использованием того же словаря:

```text
time john --wordlist=/usr/share/wordlists/rockyou.txt bruteforce.txt
```

Проверьте результат:

```text
john --show bruteforce.txt
```

Пароль второго архива отсутствует в используемом словаре.

Сделайте вывод о результате словарной атаки.

9. Оцените пространство полного перебора

Перед запуском полного перебора рассчитайте количество возможных вариантов для паролей различной длины.

Рассчитайте количество вариантов для пароля из строчных латинских букв длиной от 5 до 8 символов.

1.  Выполните подбор пароля методом полного перебора

Запустите полный перебор:

```text
time john --incremental=Lower bruteforce.txt
```

В данном режиме John the Ripper выполняет подбор паролей, используя строчные латинские буквы.

После завершения подбора получите найденный пароль:

```text
john --show bruteforce.txt
```

Зафиксируйте время выполнения атаки.

Если полный перебор не завершился за отведённое время, зафиксируйте текущую скорость перебора и количество проверенных вариантов. Продолжать вычисления после окончания практической работы не требуется.

11. Проверьте полученный пароль

Разархивируйте данные:

```text
unzip bruteforce.zip
```

Введите найденный пароль.

Убедитесь, что содержимое архива успешно извлечено.

12. Сравните результаты атак

Сравните результаты словарной атаки для `dictionary.zip` и полного перебора для `bruteforce.zip`.

13.  Проанализируйте устойчивость паролей

Рассмотрите следующие варианты:

```text
пароль, присутствующий в словаре;
случайный пароль из строчных латинских букв;
случайный пароль из строчных и прописных букв, а также цифр.
```

Для каждого варианта определите:

- возможность словарной атаки;
- размер пространства полного перебора;
- влияние длины пароля на устойчивость;
- возможность практического подбора.

Сформулируйте рекомендации по созданию устойчивых паролей.
